# Шар предсказаний

Минималистичное веб-приложение на русском языке: задай вопрос и получи случайное предсказание от магического шара. Интерфейс размещён в `public/`, API работает на Express локально и в виде Vercel Function.

**Публичный сайт:** [Открыть сайт](https://magic-8-ball-blond.vercel.app)

## Управление сервером

Требуется Node.js. Команды выполняются из папки проекта.

```powershell
npm install
npm start
```

Локальный сайт будет доступен по адресу `http://localhost:3000`. Проверить API можно в PowerShell:

```powershell
Invoke-RestMethod -Uri http://localhost:3000/api/predict `
  -Method Post -ContentType 'application/json' `
  -Body (@{ question = 'Стоит ли рискнуть?' } | ConvertTo-Json -Compress)
```

Чтобы опубликовать изменения, войди в Vercel командой `npx vercel login`, если ещё не вошёл, и выполни:

```powershell
npm run deploy
```

Полезные команды Vercel CLI:

```powershell
npx vercel list                                      # список деплоев текущего проекта
npx vercel logs --environment production            # логи production
npx vercel rollback <deployment-url-or-id>          # откат production к деплою
npx vercel remove <deployment-id> --confirm-name <deployment-id>  # удалить конкретный деплой
```

Удаление всех деплоев проекта необратимо удаляет его размещённые версии:

```powershell
npx vercel remove magic-8-ball --confirm-name magic-8-ball
```

## Как создать и развернуть такой проект

1. Установи Node.js и Visual Studio Code. Войди в GitHub Copilot Free в VS Code и открой пустую папку проекта.
2. Открой GitHub Copilot Chat, выбери режим **Agent** и вставь переиспользуемый промпт ниже. Разреши агенту создавать файлы и запускать команды. Не передавай ему пароль или токен.
3. Создай аккаунт Vercel или войди в существующий. После того как агент закончит код, локальные проверки и попросит авторизацию, выполни `npx vercel login` в терминале этой же учётной записи Windows и заверши вход в браузере.
4. Сообщи агенту, что вход завершён. Открой production-ссылку и проверь API по результатам, которые агент добавит в README.

**Переиспользуемый промпт для Copilot Agent:**

```text
Создай в текущей пустой папке веб-приложение «Шар предсказаний» на Node.js и Express, совместимое с Vercel, и доведи работу до production-деплоя.

Требования:
- Фронтенд в public/index.html, public/style.css, public/app.js: тёмный минималистичный адаптивный интерфейс на русском, поле вопроса с проверкой пустого ввода, кнопка «Спросить шар», анимация ответа внутри шара, доступные статусы и обработка ошибок. Отправляй запрос через fetch('/api/predict', { method: 'POST', ... }).
- API в api/index.js: Express-приложение, не вызывающее listen при импорте; POST /api/predict принимает { question }, возвращает HTTP 400 для пустого или нестрокового вопроса и JSON { question, answer } для допустимого вопроса. Добавь не менее 12 разных русских предсказаний: положительных, нейтральных и отрицательных.
- server.js в корне подключает Express-приложение из api/index.js, раздаёт public/ и слушает process.env.PORT || 3000.
- Добавь vercel.json с rewrite /api/(.*) -> /api/index.js, package.json со скриптами "start": "node server.js" и "deploy": "npx vercel --prod --yes"; установи express.
- Проверь локально главную страницу, успешный POST и HTTP 400 на пустой вопрос. Проверь авторизацию командой npx vercel whoami. Если её нет, попроси меня войти через npx vercel login в терминале; не запрашивай пароль или токен. После подтверждения входа выполни production-деплой.
- После деплоя проверь публичные GET / и POST /api/predict: оба должны вернуть HTTP 200, API должен содержать случайный ответ. Исправь проблемы деплоя или маршрутизации и повтори проверки.
- Создай README.md на русском с кликабельной публичной ссылкой из реального деплоя, командами запуска, проверки API, повторного деплоя, просмотра деплоев и логов, отката и удаления, а также пошаговой инструкцией и этим переиспользуемым промптом.
- Работай автономно, меняй только файлы проекта, не добавляй мониторинг. Не выдумывай URL: укажи ссылку только после успешного production-деплоя и проверки.
```
